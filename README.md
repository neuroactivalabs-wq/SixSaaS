# SixSaaS

Hub gratuito (PWA, sin backend) de **Neuroactiva Labs**: Optimizador de perfil de Google, Academia SixSaaS (4 cursos, 48 lecciones) y catálogo de 6 módulos Neuro.

- App: https://sixsaas-neuroactiva.pages.dev/
- Tienda de licencias (EMP): https://emp-neuroactiva.pages.dev/
- Versión actual: 0.5.0. Detalles en `LEEME-app.md`.

Estructura: la raíz es la app estática (`index.html`, `js/`, `css/`, `sw.js`); `tests/` contiene las pruebas.

Las licencias son offline (ECDSA P-256); aquí solo está la clave pública. El generador de licencias y la clave privada NO están en este repositorio.
