# Apps Neuro · versiones gratis (Cloudflare Pages)

Cada carpeta se publica sola en su proyecto de Cloudflare Pages al subir cambios a esta rama:
neuroresenas, neuropedidos, neurocotizaciones, neurocitador, neurorecompras y neurocrm (.pages.dev).

- Versión gratis: todas las funciones por 7 días de uso; luego pide comprar o activar.
- Activación: el cliente pega en "Activar" el código de activación que recibe por WhatsApp tras enviar su comprobante
  (también sirve abrir `https://neuro<app>.pages.dev/#activar=<código>`).
- Los códigos se verifican en el dispositivo con la clave pública; los generadores son privados y no están aquí.
